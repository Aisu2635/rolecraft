# RoleCraft

RoleCraft is a browser-only AWS IAM policy builder. It helps you assemble least-privilege roles, permission policies and trust policies from AWS's published service reference data, entirely client-side with no backend and no credentials.

Live site: https://rolecraft.omhinge.cloud

## Data

AWS service and action data comes from the AWS Service Authorization Reference (servicereference.us-east-1.amazonaws.com) and is refreshed weekly. RoleCraft isn't affiliated with or endorsed by Amazon Web Services.
